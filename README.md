# Aashish Mahato portfolio

React portfolio built with Vite.

## Run it

```sh
npm install
npm run dev
```

Open the local URL shown by Vite. To make a production build, run `npm run build`.

## Add your hero video

Your original is saved at `source-videos/hero.mov`. The site plays the short web version at `public/videos/hero.mp4`, with `hero-poster.jpg` displayed while it loads. The video autoplays muted and loops.

## Personalize it

Edit the headline, introduction, services, and sample project data in `src/App.jsx`. The six project cards are clearly marked as concepts until your real work is added. Styles are in `src/style.css`.
